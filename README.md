 Task Manager – React Capstone Project

Welcome to **Coffee Task Manager**, a React-based single-page application built for managing tasks in a cozy coffee shop environment. This project is developed as part of **MTM6404 Web Applications – Capstone Iteration 4**.

---

## 🌟 Project Overview

This application helps users (coffee shop staff or anyone) organize their tasks by creating task boards (lists), adding priority-based items, and managing them interactively. It's a dynamic and responsive app powered by **React, React Router, Context API**, and **localStorage** for data persistence.

## ✨ Features Implemented

✅ Minimum 5 single-file React components  
✅ Component using `children` prop  
✅ List rendering and conditional rendering  
✅ React Router with 2 dynamic routes  
✅ Navbar, footer, list view  
✅ Form to add new lists  
✅ Ability to delete lists  
✅ View a single list at a time  
✅ Add tasks with priority  
✅ Sort tasks by priority  
✅ Toggle completed/incomplete tasks  
✅ Show/hide completed items  
✅ Delete individual tasks  
✅ Context API for global state  
✅ Persistent data via `localStorage`  
✅ Responsive design across screen sizes  
✅ Coffee-themed color palette and UI
